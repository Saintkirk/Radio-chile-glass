# Skills externas revisadas

Fuente: https://github.com/Saintkirk/skills (repositorio redirigido por GitHub a emilkowalski/skills, rama main).

Skills identificadas: animate, animate-expo, review-animations, improve-animations, find-animation-opportunities, animation-vocabulary, apple-design, prototype, pick-ui-library, write-swift, ask-sonner y emil-design-eng.

La skill más relevante para Radio Chile Glass es `animate-expo`. Sus recomendaciones principales son usar Reanimated en lugar de Animated para gestos y movimiento continuo, mantener las animaciones en el UI runtime, respetar reduced motion, evitar animar layout, usar targets táctiles de al menos 44 pt/48 dp y reservar las transiciones de pantalla para las opciones nativas de Expo Router. También recomienda curvas ease-out/ease-in-out y animaciones de interacción normalmente menores de 300 ms.

La referencia del usuario se aplicará como dirección visual, no se copiarán instrucciones ejecutables del repositorio sin revisión.
